## The joke

> The water cooler is the only meeting where everyone shows up on time — and nobody takes notes.

## How it works

Run `main.py` (Python 3.13). It writes the entry to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` if the variable is
unset) as a single line with no trailing newline, validating that the text
is 1–199 characters first.
